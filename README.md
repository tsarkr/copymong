# 카피몽 (CopyMong) 🐵

**소상공인을 위한 AI 문구 생성기** — 리뷰 답글, 상품 설명, 블로그 글, 인스타 캡션을 한 번에.

네이버 플레이스에 답글을 달고, 스마트스토어에 상품을 올리고, 블로그와 인스타를 운영하는데
매번 문구 쓰느라 시간 쓰지 마세요. 정보를 입력하면 10~20초 안에 복사해서 바로 붙여넣을 수 있는 문구가 완성됩니다.

> 임베드/연동이 필요 없습니다. 만든 문구를 복사해서 네이버 플레이스, 스마트스토어, 네이버 블로그, 인스타그램에 붙여넣으면 끝입니다.

## 기능 4종

| 도구 | 입력 | 출력 |
|---|---|---|
| ⭐ 리뷰 답글 | 리뷰 원문, 별점, 말투 | 답글 3종 (정중한 / 친근한 / 짧은) |
| 🛍️ 상품 설명 | 상품명, 특징, 타겟, 가격 | 헤드라인 + 상세 본문 + SEO 키워드 10개 |
| ✍️ 블로그 글 | 키워드, 주제 | 제목 후보 5개 + 본문 + 해시태그 |
| 📸 인스타 캡션 | 주제, 분위기 | 캡션 + 해시태그 20개 |

## 왜 돈이 안 드나요?

구매자 본인의 **Google Gemini API 키**를 사용합니다 (BYOK 방식).
Google AI Studio에서 무료로 발급되며, 무료 등급만으로도 일상적인 문구 생성에는 충분합니다.
월 구독료도, 건당 과금도 없습니다.

## 설치 (5분)

필요한 것: Node.js 18 이상, Gemini API 키

```bash
# 1) API 키 발급 (무료): https://aistudio.google.com/apikey

# 2) 실행
git clone <이 저장소 주소>
cd copymong
cp .env.example .env   # .env에 GEMINI_API_KEY 입력
node server.js
# 브라우저에서 http://localhost:8480 접속
```

API 키를 `.env`에 넣지 않고, 화면 상단 입력칸에 그때그때 넣어도 됩니다.
